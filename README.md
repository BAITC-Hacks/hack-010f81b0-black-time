# ekt.kz — онлайн сатушы-кеңесші

Қазақ тіліндегі интерактивті frontend прототипі. HTML, CSS және JavaScript толықтай **бір `index.html` файлында**. Сыртқы кітапханалар, қаріптер немесе суреттер жүктелмейді; суреттер — файл ішіндегі SVG иллюстрациялар.

## Іске қосу

`index.html` файлын Chrome, Edge, Firefox немесе Safari браузерінде ашыңыз. Орнату, build, API кілті және сервер қажет емес. Интернетсіз жұмыс істейді.

## Демо ағындары

1. Бастапқы диалог IEK C16 тауарын көрсетеді. `− / +` арқылы санын таңдаңыз немесе сан өрісіне жазыңыз.
2. **Себетке қосу** батырмасы растау сұрағын шығарады. Осы сәтте себет өзгермейді.
3. **Иә, қосу** басылғанда немесе дәл «Иә, қосу» деп жазғанда тауар демо себетке түседі. **Жоқ, өзгерту** сан таңдауға қайтарады.
4. **10 дана керек** дайын сұрағы 10 дана × 1 500 ₸ = 15 000 ₸ растауын көрсетеді. Басқа тауарды таңдаған болсаңыз, сұрақ соңғы көрсетілген тауарға қатысты болады. Оң жақтағы **Себетке қосу** сценарийі әрдайым IEK моделін пайдаланады.
5. **Аналог табу** сұрағы қоймада жоқ ABB моделін және Schneider нұсқасын көрсетеді. Ұқсас сипаттамалары мен ажырату қабілетіндегі айырмашылығы жазылған.
6. **Жеткізу туралы** батырмасы ойдан алынған төлем/жеткізу шарттарын көрсетеді.
7. Скрепка арқылы PDF, Excel, Word, JPEG немесе PNG таңдаңыз: тек файл атауы, түрі мен көлемі чатқа шығады. 10 МБ шегі бар. Файл мазмұны оқылмайды және ешқайда жіберілмейді.
8. **Себет** батырмасы ағымдағы тізімді, санын және жалпы сомасын ашады. **Тапсырысты рәсімдеу** тек демо түсіндірмесін көрсетеді.

Қосымша мәтіндік мысалдар: `кабель`, `Schneider Easy9`, `IEK 10 дана керек`, `ABB C16 бар ма?`, `жеткізу шарттары`, `сертификат`.

## Құрылымы

- `PRODUCTS` — төрт ойдан алынған тауар: артикул, атау, сипаттама, баға, қалдық және өлшем бірлігі.
- `state` — осы бет ашық тұрған кездегі себет, карточкалар және күтілетін растау күйі.
- `replyTo()` — дайын жауаптарды кілт сөздер бойынша таңдайды. ЖИ емес.
- `askConfirmation()` және `confirm()` — екі қадамды қосу. Қайта басу тауарды екі рет қоспайды; себеттегі санмен бірге жалпы сан қалдықтан аспайды.
- `renderCart()` — себет, жалпы сома, барлық badge пен карточкалардың қолжетімді санын жаңартады.
- CSS media queries — кең экрандағы орталық чат, планшет және 700 px-ге дейінгі толық экранды мобильді көрініс.

## Шектеулері

Барлық деректер мен шарттар ойдан алынған. Нақты ekt.kz API-і, Basic Auth, бэкенд, ЖИ, төлем немесе нақты тапсырыс жүйесі қосылмаған. Құпиясөздер кодқа енгізілмеген. Себет пен чат тек JavaScript жадында сақталады; парақшаны жаңарту бәрін бастапқы күйге қайтарады. Чат тақырыбындағы қайта бастау батырмасы тек диалогты жаңартады, себетті сақтайды.

Себет белгісі тауарлардың жалпы санын көрсетеді; кабель метрмен есептеледі. SVG суреттер нақты өндіруші фотолары емес. Аналог ұсынысы инженерлік сәйкестікті растамайды.

Қолжетімділік: қазақ тілінің `lang` атрибуты, батырма белгілері, пернетақтамен басқару, модальдағы фокус шектеуі, Escape арқылы жабу және қозғалысты азайту баптауын қолдау.
