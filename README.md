# ekt.kz — онлайн сатушы-кеңесші

Қазақ тіліндегі frontend прототипі. HTML, CSS және JavaScript бір `index.html` файлында. Каталогты команданың backend серверіне қосуға арналған клиент дайын; нақты сервер адресі мен тауар өрістері әлі келісілмеген. Әдепкіде барлық көрініс ойдан алынған деректермен жұмыс істейді.

## Іске қосу

**Демо:** `index.html` файлын браузерде ашыңыз. Орнату, сервер және интернет қажет емес.

**Нақты каталог:** backend жасаушысынан сервер адресі мен JSON үлгілерін алған соң, `index.html` ішіндегі `CATALOG_CONFIG` баптауын өзгертіңіз. Бетті VS Code Live Server арқылы HTTP адресімен ашыңыз. Backend сол frontend адресіне CORS рұқсатын беруі керек. Толық нұсқаулық — [INTEGRATION.md](INTEGRATION.md).

## Дайын мүмкіндіктер

- Каталог: алдыңғы/келесі бет, тауар карточкалары және толық мәлімет терезесі.
- Жүктелу, бос тізім, қате және қайта көру көріністері. Баға немесе қалдық берілмесе, «белгісіз» болып көрсетіледі.
- Демо чат: тауар туралы жауап, сан таңдау, нақты растаудан кейін себетке қосу, аналог және сатып алу шарттары.
- PDF, Excel, Word, JPEG және PNG тіркеу көрінісі: файлдың атауы, түрі мен көлемі көрсетіледі. Файл мазмұны оқылмайды және серверге жіберілмейді; шегі — 10 МБ.
- Компьютер және мобильді экрандарға бейімделген қазақша интерфейс.

## Тексеріп көру

1. Каталогтағы келесі бетке өтіп, тауардың толық мәліметін ашыңыз. Демода екі бет бар, әрқайсысында 20 синтетикалық тауар болады. Екінші беттің бірінші ID-і — `515291`; бұл нақты ekt.kz тауарының көшірмесі емес.
2. Чаттағы тауардан сан таңдап, **Себетке қосу** басыңыз. Себет тек **Иә, қосу** растауынан кейін өзгереді. **Жоқ, өзгерту** растауды тоқтатады.
3. **Аналог табу** арқылы қоймада жоқ тауардың баламасын, **Жеткізу туралы** арқылы демо шарттарды көріңіз.
4. Скрепка арқылы файл таңдап, себет тізімі мен жалпы сомасын ашыңыз. **Тапсырысты рәсімдеу** тек демо түсіндірмесін көрсетеді.

Каталогтың қосымша күйлерін демо режимінде мына URL параметрлерімен ашуға болады:

| Адрес соңы | Көрініс |
| --- | --- |
| `index.html?catalogDemo=empty` | Бос каталог |
| `index.html?catalogDemo=error` | Бірінші тізім сұранысы қате береді; қайта көру сәтті аяқталады |
| `index.html?catalogDemo=slow` | Ұзартылған жүктелу көрінісі |

## Файлдар және шекаралар

- `index.html` — интерфейс, демо деректер, каталог клиенті және барлық стиль.
- `INTEGRATION.md` — backend келісімі, баптау үлгісі және backend жасаушысына дайын хабарлама.
- `README.md` — іске қосу мен демонстрация нұсқаулығы.
- `tests/` — каталог клиенті мен интерфейс күйінің автоматты тексерістері.

## Автоматты тексеру

Node.js орнатылған ортада жоба бумасынан орындаңыз. Қосымша кітапхана орнатылмайды:

```sh
node --test tests/catalog.test.cjs tests/frontend.test.cjs
```

Тесттер нақты серверге сұраныс жібермейді. API маршруттары, ID, жауап пішімі, қате/timeout/abort, пагинация, ескірген жауаптардан қорғану және демо себеттің растауы тексеріледі. Интерфейс тесттері жеңіл DOM адаптерін қолданады; олар браузердегі визуалды тексеруді алмастырмайды.

Каталогтың `api` режимі тек команданың backend серверінен оқиды. Қате шыққанда демо дерекке жасырын ауыспайды. API каталогындағы тауарлар демо чатқа немесе себетке қосылмайды: нақты себет endpoint-тері әлі келісілмеген. Чат, аналогтар, сатып алу шарттары және себет әзірге демонстрациялық күйде қалады. ЖИ және нақты іздеу қосылмаған.

Frontend ішінде ekt.kz BasicAuth логині, құпиясөзі немесе төлем деректері жоқ. API авторизациясы backend командасымен бөлек келісіледі. Нақты серверге қосылу әзірге тексерілген жоқ. Себет пен диалог бет жадында сақталады; бетті жаңартқанда бастапқы күйге оралады.
