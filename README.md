# hack-010f81b0-black-time
Hackathon team repository for Black Time

## Backend: ekt.kz каталогына қосылу

Бұл — backend-тің бастапқы кезеңі. Браузер немесе frontend біздің FastAPI серверіне сұраныс жібереді, сервер ekt.kz API-інен JSON алып қайтарады. Сыртқы API-ге кіру деректері тек серверде сақталады.

### Негізгі файлдар

| Файл | Мақсаты |
| --- | --- |
| `backend/main.py` | FastAPI қолданбасы, маршруттар, параметрлерді тексеру және CORS. |
| `backend/ekt_client.py` | ekt.kz-ке Requests арқылы сұраныс жіберу, BasicAuth, таймауттар және қателерді өңдеу. |
| `tests/test_api.py` | Нақты желіге шықпайтын mock тесттер. |
| `requirements.txt` | Қажетті Python кітапханалары. |
| `.env.example` | Құпиясыз баптау үлгісі. |
| `.env` | Өзіңіз жергілікті жасайтын кіру деректері; Git-ке қосылмайды. |
| `.gitignore` | `.env`, виртуалды орта және уақытша файлдарды Git-тен алып тастайды. |

### Windows PowerShell арқылы дайындау

VS Code терминалын **репозиторийдің түбірінде**, яғни осы `README.md` тұрған қалтада ашыңыз. Төмендегі барлық командалар сол қалтадан орындалады. Алдымен Python 3.10 немесе одан жаңа нұсқасы және Windows Python Launcher (`py`) орнатылған болуы керек.

```powershell
py -3 --version
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Мұнда FastAPI, Uvicorn, Requests, python-dotenv, pytest және httpx орнатылады. `.venv` — тек осы жобаға арналған Python ортасы. Оны бөлек белсендіру қажет емес: командалар оның `python.exe` файлын тікелей пайдаланады.

`.env` файлын **тек ол жоқ болса** жасаңыз:

```powershell
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item -LiteralPath .env.example -Destination .env
}
```

VS Code арқылы түбірдегі `.env` файлын ашып, `EKT_LOGIN` және `EKT_PASSWORD` мәндерін жергілікті енгізіңіз. Үлгіде `EKT_LOGIN=apiuser`, ал құпиясөз бос. Құпиясөзді чатқа, README-ге, тесттерге немесе frontend-ке көшірмеңіз. Бар `.env` файлын үстінен жазбаңыз және Git-ке қоспаңыз.

Сервер `.env` файлын репозиторий түбірінен оқиды. Операциялық ортада алдын ала берілген `EKT_LOGIN` немесе `EKT_PASSWORD` айнымалылары басым болады: `.env` оларды алмастырмайды. Баптауды өзгерткен соң серверді қайта іске қосыңыз.

### Серверді іске қосу

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```

Терминалды ашық қалдырыңыз. Сервер тек жергілікті компьютерде қолжетімді; тоқтату үшін `Ctrl+C` басыңыз.

Браузерде ашыңыз:

- [Сервердің күйі: /health](http://127.0.0.1:8000/health) — `{"status":"ok"}` қайтарады. ekt.kz-ке сұраныс жібермейді және кіру деректерін қажет етпейді.
- [Swagger құжаттамасы: /docs](http://127.0.0.1:8000/docs) — маршрутты таңдап, **Try it out**, кейін **Execute** арқылы тексеріңіз.
- [Каталогтың бірінші беті](http://127.0.0.1:8000/products?page=1).
- [Каталогтың екінші беті](http://127.0.0.1:8000/products?page=2).
- [ID 515291 тауары](http://127.0.0.1:8000/products/515291).

Каталог маршруттары үшін жарамды кіру деректері және ekt.kz-ке желілік қолжетімділік қажет. `/health` жауабы сыртқы интеграцияның жұмыс істейтінін растамайды.

### Frontend-пен келісім

Frontend сұраныстарды `http://127.0.0.1:8000` мекенжайына жібереді. ekt.kz логині мен құпиясөзін браузерге берудің қажеті жоқ.

| Біздің маршрут | Сыртқы API сұранысы |
| --- | --- |
| `GET /health` | Сыртқы сұраныс жоқ. |
| `GET /products?page=1` | `GET https://ekt.kz/api/products?page=1` |
| `GET /products/515291` | `GET https://ekt.kz/api/products/detail?id=515291` |

`page` әдепкіде `1`; `page` және `product_id` оң бүтін сан болуы керек. Әр каталог сұранысы тек бір бетті алады. **Тауардың ID нөмірі мен артикулы бір ұғым емес**: `/products/{product_id}` артикул бойынша іздемейді.

Каталогтың сәтті жауабының келісімі:

```text
{
  "source": "ekt.kz",
  "data": <сыртқы API қайтарған JSON>
}
```

`data` сыртқы JSON құрылымын сақтайды. Оның объект, тізім немесе басқа JSON мәні екені алдын ала бекітілмеген. `name`, `price`, `stock` сияқты өрістердің бар-жоғы әзірге расталмаған; жоқ мәндер нөлге айналдырылмайды. Нақты жауап құрылымы тексерілгеннен кейін frontend оны өңдеуге бейімделеді.

CORS мына жергілікті origin-дерге рұқсат береді:

- `http://localhost:5500`
- `http://127.0.0.1:5500`
- `http://localhost:5173`
- `http://127.0.0.1:5173`

Frontend-ті осы origin-дердің бірінен іске қосыңыз. Барлық origin-ге `*` рұқсаты берілмейді.

### Қателерді түсіну

Қате туралы ақпарат JSON жауабының `detail` өрісінде беріледі. FastAPI параметр қатесінде бұл өріс қателер тізімі болады, ал сыртқы API қатесінде түсінікті хабарлама болады.

| HTTP коды | Мағынасы және әрекет |
| --- | --- |
| `422` | `page` немесе `product_id` жарамсыз. Оң бүтін сан жіберіңіз. |
| `503` | Сервердің `EKT_LOGIN` немесе `EKT_PASSWORD` мәні бапталмаған. Жергілікті баптауды тексеріп, серверді қайта іске қосыңыз. |
| `504` | ekt.kz-ке қосылу немесе жауап күту уақыты бітті. Желіні тексеріп, кейін қайталаңыз. |
| `502` | Қосылу қатесі, JSON емес жауап, redirect немесе сыртқы HTTP қатесі. Сыртқы `401/403` кезінде сервердің ekt.kz-ке кіру деректерін тексеріңіз. |

Сыртқы HTTP қатесі автоматты түрде «тауар жоқ» дегенді білдірмейді. Қате жауаптарда құпиясөз, Authorization тақырыбы, traceback немесе сыртқы сервердің толық HTML қатесі берілмейді.

### Тесттер

Бөлек PowerShell терминалында, жоба түбірінен орындаңыз:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Mock тесттер `/health`, каталог пен тауар сұраныстарының параметрлерін, жауап келісімін, жарамсыз кірісті, кіру деректерінің жоқтығын, таймаутты, сыртқы HTTP қателерін және JSON емес жауаптарды тексереді. Олар желіге шықпайды және нақты логин/құпиясөзді қажет етпейді. Тесттердегі барлық дерек жасанды; олар нақты ekt.kz жауабының үлгісі емес.

Mock тесттердің өтуі нақты интеграция тексерілді дегенді білдірмейді. Нақты кіру деректері мен желілік рұқсат болғанда, бөлек тексеру үшін каталогтың бір бетін және `/products/515291` маршрутын сұрату жеткілікті. Нақты API-дің JSON құрылымы осы тексеруге дейін расталмаған болып қалады.

2026-09-23 күнгі тексеру: Python 3.14.0 ортасында **87 mock тест өтті**. Starlette тест клиенті `httpx` қолдауына қатысты бір deprecation ескертуін берді; ол тесттердің өтуіне кедергі болмады. `pip check` тәуелділік қайшылығын таппады.

Жоғарыдағы дәл Uvicorn командасы `--reload` параметрімен тексерілді: `/health` және `/docs` — `200`, кіру деректері жоқ `/products?page=1` — `503`. Уақытша сервер тексеруден соң тоқтатылды. **Нақты ekt.kz API-і тексерілген жоқ:** ортада `EKT_LOGIN`/`EKT_PASSWORD` және жергілікті `.env` болмады.

### Осы нұсқаның шектеулері

Requests сұраныстары синхронды орындалады; қосылу таймауты — 5 секунд, оқу таймауты — 15 секунд. HTTPS сертификаты тексеріледі, redirect автоматты орындалмайды, клиент еркін сыртқы URL бере алмайды. Автоматты қайталау және сервер іске қосылғанда толық каталогты жүктеу жоқ.

Бұл нұсқа каталогтың бетін және тауарды ID бойынша алуға арналған. Тауарды атау/артикул бойынша іздеу, ЖИ мен чат логикасы, аналогтар, сатып алу шарттары, файл өңдеу, растаудан кейін себетке қосу, төлем, дерекқор, Docker және frontend әлі іске асырылған жоқ.
